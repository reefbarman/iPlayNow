## Install

iPlayNow isn't on the App Store. You sideload it with your own Apple ID, and a free Apple ID is enough.

**SideStore or AltStore (recommended, gets updates):** add this source, then install iPlayNow from it:

```
https://raw.githubusercontent.com/reefbarman/iPlayNow/main/altstore-source.json
```

**Sideloadly or another signer:** download `iPlayNow.ipa` from the [latest release](https://github.com/reefbarman/iPlayNow/releases/latest) and install it as you would any other IPA.

Then follow [Sign-in and library](sign-in-and-library.md) to get started. Every feature and setting is covered in the guides in the sidebar.

You need a GeForce NOW account, and the library shows the games you own on stores you've linked to GeForce NOW.

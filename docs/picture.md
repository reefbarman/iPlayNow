# Picture

iPlayNow decodes the stream with the phone's hardware H.265/H.264 decoder and draws it with Metal at the screen's native resolution.

## Video

Settings › Video, or per game (see [Per-game video settings](sign-in-and-library.md#per-game-video-settings)).

- **Resolution** and **Frame rate:** up to 4K and 120 fps.
- **Bitrate:** up to 100 Mbps. With **Auto bitrate** on, this is the starting bitrate for each Wi-Fi network (see [Connection](connection.md)).
- **Codec:** H.265 or H.264.
- **HDR:** needs H.265 and a game that supports it.

Your membership decides the most GeForce NOW will stream. 1440p, 4K, 120 fps and HDR need Ultimate.

GeForce NOW fixes these when it sets up the rig, so change them before you start a game. The stream menu shows what the session is using.

## Display

Settings › Display. These can also be changed mid-game from the stream menu.

- **Picture:** Fit shows the whole picture, with black bars where the screen is a different shape to 16:9. Zoom fills the screen and crops the edges.
- **Upscaling:** Sharp, MetalFX Spatial (enlarges the picture to the screen's resolution) or MetalFX 4K (enlarges it to 3840×2160 and then scales it down to the screen).
- **120 Hz screen:** on ProMotion iPhones, gets each frame on screen sooner, for a little more battery.
- **Stats:** Off, Simple or Advanced. Stats sit in the black bar above the picture.

## Frame generation

Settings › Display › **Frame generation (experimental)**.

Makes an extra frame between each pair the stream sends, so 30 fps looks like 60 and 60 like 120, for half a frame of extra delay. It follows the game's real frame rate, so a game running at 60 in a 120 fps stream still gets it on a 120 Hz screen.

Tap the bottom-right corner of the stream to turn it on and off while you play.

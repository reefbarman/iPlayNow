# The stream screen

## Corner shortcuts

The corners of the stream have hidden buttons, so nothing covers the game until you need it.

| Corner       | What it does                                                                         |
| ------------ | ------------------------------------------------------------------------------------ |
| Top right    | Tap, then the gear, for the stream menu                                              |
| Top left     | Tap, then the Xbox logo (GeForce NOW's in-game menu), the keyboard or the mic button |
| Bottom right | Turn [frame generation](picture.md#frame-generation) on and off                      |

With a controller, hold **View + Menu** for a second to open the stream menu.

## The stream menu

The game keeps running behind the menu. From it you can:

- Change display, controller, virtual controls and stats settings mid-game.
- See the resolution, frame rate, bitrate and codec the session is using.
- [Check connection](connection.md#check-connection).
- Open the [Controller Test](controllers.md#controller-test).
- See the phone's battery and temperature.
- Type with the keyboard, mute the mic and save a screenshot.
- [Share diagnostics](troubleshooting.md#reporting-a-problem) or report a problem, without leaving the game.
- **Quit game**, which ends the session on GeForce NOW so it doesn't keep running on your account. It needs a second press to confirm.

## Typing with the keyboard

Tap the top-left corner, then the keyboard button, or choose **Type with the keyboard** in the stream menu.

Each letter goes to the game as you type, so it works in logins, password fields and chat. Return and delete work as normal keys, and a bar above the keyboard adds Esc, Tab and the arrow keys.

## Screenshots

Open the stream menu and choose **Save screenshot to Photos**.

It's the whole game picture at the stream's resolution, without the virtual controls or black bars, and HDR games are converted to normal colour. The first time, iOS asks to let iPlayNow add photos. It can only add photos, not see your library.

## Battery and heat

The stream menu shows the battery and the phone's temperature, and the app warns you when the phone gets hot.

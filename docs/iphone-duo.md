# iPhone Duo

iPlayNow shares its player with [iPlay5](https://github.com/reefbarman/iPlay5), so it's tuned for the iPhone Duo's near-square inner screen.

- **Outer screen:** the game waits there until you unfold.
- **Inner screen:** the game plays there, using the whole screen.
- **Folding:** pauses the stream.

On the inner screen, **Fit** shows the whole 16:9 picture with black bars above and below, where the stats sit. **Zoom** fills the screen and crops the sides. See [Picture](picture.md#display).

# Connection

GeForce NOW sets the bitrate when a game starts, so connection changes apply from the next game.

## Auto bitrate

Settings › Video › **Auto bitrate**. On by default.

It learns the bitrate that works on each Wi-Fi network, starting from the **Starting bitrate**. After a clean game it tries a little more next time, and after a game that dropped video it uses less.

On mobile data, and for games with their own video settings, the bitrate setting is used as is.

**Forget learned bitrates** clears what it has learned.

## Check connection

In the stream menu, under **Connection**.

It watches the next 20 seconds of the stream for lost video, then tells you how the connection is doing and can suggest a bitrate. Tap **Use … Mbps next time** to use it from your next game.

Play something busy while it checks, since GeForce NOW sends much less on menus and quiet scenes.

## Reconnecting after a dropout

If the connection drops mid-game, iPlayNow gets the same rig back from GeForce NOW, so your game is still where you left it. It tries three times, then offers **Reconnect** on the screen that follows. Closing that screen ends the session.

## Tips

- Turn on **Stats** (Settings › Display) to see bitrate, ping and loss.
- Use 5 GHz or 6 GHz Wi-Fi, especially at high resolutions and bitrates.

# iPlayNow feature guides

Everything iPlayNow does, grouped by topic. The [main README](https://github.com/reefbarman/iPlayNow#readme) has the highlights, install steps and first-run setup. The [changelog](https://github.com/reefbarman/iPlayNow/blob/main/CHANGELOG.md) lists what changed in each release. These guides are also published at [reefbarman.github.io/iPlayNow](https://reefbarman.github.io/iPlayNow/).

| Guide                                                       | What's in it                                                                                                   |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| [Sign-in and library](sign-in-and-library.md)               | Providers and sign-in, the cover grid, stores, sorting, per-game video settings, signing out                   |
| [Picture](picture.md)                                       | Resolution, frame rate, bitrate, codecs, HDR, Fit/Zoom, upscaling and MetalFX, 120 Hz, frame generation, stats |
| [Controllers](controllers.md)                               | Supported controllers, the Xbox and Home buttons, rumble, gyro aiming, Controls Guide, Controller Test         |
| [Touch and virtual controls](touch-and-virtual-controls.md) | On-screen controls and their options, touch as a mouse, no-controller prompt                                   |
| [Connection](connection.md)                                 | Auto bitrate, Check connection, reconnecting after a dropout                                                   |
| [Audio](audio.md)                                           | Game audio, microphone and party chat                                                                          |
| [The stream screen](stream-screen.md)                       | Corner shortcuts, the stream menu, typing with the keyboard, screenshots, battery and heat, quitting           |
| [iPhone Duo](iphone-duo.md)                                 | Inner and outer screens, folding                                                                               |
| [Help and troubleshooting](troubleshooting.md)              | Share diagnostics, reporting a problem, known limitations                                                      |
| [Licences and source code](licensing.md)                    | What the AGPL means for you, Settings › About, getting the source for a version, bundled components            |
| [Privacy policy](privacy.md)                                | What iPlayNow keeps on your device, who it talks to, permissions and diagnostics                               |

Settings paths in these guides look like **Settings › Display**. Open Settings from the gear in the library, or during a stream from the top-right corner or by holding **View + Menu**. Most settings are also in the stream menu, so you can change them while you play.
